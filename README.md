# FactoryPulse

A mobile-first factory management demo with simulated data. The Shift Planner stores its state in your browser's local storage; it has no backend or login.

## Run locally

1. Install Node.js (which includes npm) from [nodejs.org](https://nodejs.org/).
2. In this project folder, open a terminal and run:

   ```sh
   npm install
   npm run dev
   ```

3. Open the local address printed by Vite, usually `http://localhost:5173`.

The browser saves demo changes in local storage. Use the same browser to keep seeing them.
